WHAT THIS IS
------------
Your original site was a single HTML page with anchor-based navigation
(#produits, #battants, #apropos...). Google/AI engines could only see one
URL. This package turns it into a real multi-page site while keeping the
exact same visual design (same fonts, colors, layout system).

HOW TO DEPLOY
-------------
1. This assumes the site lives at the DOMAIN ROOT (https://prompolu.com/),
   which matches what I found when I crawled it. All internal links and
   asset paths use root-relative URLs (e.g. /assets/style.css,
   /coulissants.html) — so upload the whole folder structure AS-IS to your
   web root, keeping the assets/ and conseils/ subfolders intact.
2. Back up your current live index.html before overwriting it.
3. Upload everything (via your host's File Manager, FTP/SFTP, or however
   you currently publish the site) to the same place the current
   index.html lives.
4. Open https://prompolu.com/ afterward and click through every nav link
   to confirm each page loads.

AFTER DEPLOYING — SUBMIT TO SEARCH ENGINES
-------------------------------------------
1. Google Search Console (search.google.com/search-console): add the
   property if not already done, then Sitemaps > add
   "https://prompolu.com/sitemap.xml", and use "Request indexing" on each
   of the 8 URLs above.
2. Bing Webmaster Tools: same idea (Bing also feeds some AI answer engines).
